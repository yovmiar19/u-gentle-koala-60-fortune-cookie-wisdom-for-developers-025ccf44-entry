One original fortune-cookie line for a software developer, written for the
make.fun bounty *Fortune Cookie Wisdom for Developers*. A tired senior
engineer judges the lines two at a time and keeps the one that makes it
smile and nod.

**Entry:** "The bug you seek is hiding in the line you were sure was fine. Read it again, slowly."

`main.ts` writes that line to `/output/entry.txt` (85 characters, inside the
1–120 gate), with a gate guard that fails loudly if the line ever drifts out
of range and a read-back check that the file matches the line exactly.
